# CodeBuddy 🤖

CodeBuddy is an AI-powered learning assistant designed to help students understand programming and computer science concepts through simple explanations, examples, and interactive questions.

## 🚀 Current Features

- Flask-based backend
- REST API for asking questions
- Input validation
- Separate AI service layer
- Python virtual environment
- Environment variable protection
- Git-based version control

## 🛠️ Tech Stack

- Python
- Flask
- OpenAI API
- Git & GitHub
- HTML/CSS/JavaScript (coming soon)
